# Profile data

`profile-data.json` is used by the Next.js application for shared profile details, social links, metadata, structured data, and sitemap URLs. Update this file to change those values.

Education, experience, and about/contact content remains in `../content/about.html`. Project cards are in `../lib/projects.ts`; Home and Projects layout is implemented in the Next.js app routes.

The age shown on the site is calculated from `personal.age` at runtime using the birth year, month, and day.
